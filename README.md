# Open LMX Website

Starter website for Open LMX.

## Current Site

This repository currently contains a simple static `index.html` landing page.

## Local Preview

Open `index.html` in a browser, or serve the repository with any static file server.

## Deployment

This site can be deployed with GitHub Pages using branch-based deployment.

To activate deployment:

1. Open **Settings → Pages**.
2. Set **Source** to **Deploy from a branch**.
3. Select the `main` branch and `/root` folder.
4. Save.

Expected GitHub Pages URL: https://open-lmx.github.io/website/
